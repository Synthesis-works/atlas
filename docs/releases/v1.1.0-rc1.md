# Atlas v1.1.0-rc1

This release marks the completion of **Phase A (Benchmark Authoring)** Core. The underlying Benchmark models have been formalized into a strict state machine with robust referential integrity and an API surface suitable for integration.

## Features Completed
- **Benchmark CRUD**: Full lifecycle management of a benchmark definition.
- **Versioning Engine**: Strict enforcement of the "one active editable version per benchmark" rule.
- **Lifecycle Actions**: Secure transitions (`/validate`, `/publish`, `/archive`) with invariant checks ensuring datasets, capabilities, categories, and metrics are bound prior to publishing.
- **Dataset Relationship Integration**: Normalized referential integrity linking benchmark versions to their dataset bindings via proper Association Tables (M2M) rather than simple arrays.
- **Typed Domain Events**: A robust internal event bus foundation (`BenchmarkCreatedEvent`, `BenchmarkPublishedEvent`, etc.) natively emitted by domain services.

## Breaking Changes & Migration Notes
- **API**: Internal benchmark schema heavily modified. Users creating a benchmark now explicitly start in `PROPOSAL` state. 
- **Database**: The `dataset_version_ids` array column on `BenchmarkVersion` has been dropped. All queries must now join against the `benchmark_version_dataset_link` association table. Application-layer DTOs retain backwards compatibility, dynamically exposing `dataset_version_ids` array representations.

## Known Limitations & Deferred Work
- **Event Bus Pipeline**: The `DomainEvent` architecture is generating events effectively, but lacks a publisher routing them to an external message queue (e.g., Kafka/RabbitMQ).
- **Metric Engine Validation**: Validation checks assert an `evaluation_strategy_id` exists, but deep verification against a true metrics engine is deferred until Phase C (Evaluation).

## Test Coverage Summary
- **API Layer**: 100% coverage on route delegation and HTTP error mapping.
- **Domain Layer**: 100% coverage on the transition matrix (`O(N^2)` validation).
- **Concurrency**: Verified robust pessimistic locking for concurrent version creation attempts.
