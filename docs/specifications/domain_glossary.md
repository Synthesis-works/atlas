# Domain Glossary

This document establishes the canonical terminology for the Atlas platform to eliminate ambiguity across all backend implementations, API contracts, and team discussions.

| Term | Definition |
| :--- | :--- |
| **Benchmark** | Logical benchmarking project (contains multiple versions). |
| **Benchmark Version** | Immutable executable snapshot. |
| **Dataset** | Logical dataset. |
| **Dataset Version** | Immutable dataset snapshot. |
| **Execution** | A single benchmark run against a specific model. |
| **Evaluation** | Scoring produced from an execution. |
| **Report** | Human-readable summary of an evaluation. |
| **Capability** | AI ability being measured (e.g., Code Generation, Reasoning). |
| **Metric** | Numerical scoring function used during evaluation. |
